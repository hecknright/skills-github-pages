Work Based Projects

All of my projects are listed below, each representing a unique challenge and solution.

Many of these are projects are ongoing and continue to evolve over time.

PROJ-01Improve Incident Response Times Through Automation

Context

An e-filing platform held to a 99.95% uptime SLA, with filing deadlines everyday up till midnight. Outages caused missed deadlines, court declarations, and lost revenue.

What I did

Built out monitoring, alerting, bug fixes and automation with Python, C#, Azure Functions, and runbooks.

Outcome

Incident response time dropped from 10 minutes to 2. Missed-deadline incidents that required court declarations fell from 25 a quarter to an average of 1 a quarter.

PROJ-02E2E Financial Reconciliation Through Automated Recovery

Context

Outstanding orders and uncollected fees needed to be reconciled. The number of affected orders and the financial impact were known to be significant but not fully quantified.

What I did

Built automated reconciliation using Azure Function Apps and runbooks that automated data collection, processing, audit logging and reporting. This included building out web service automation to interact with Court API's to recover affected orders and collect fees, as well as a reporting dashboard to track progress and results.

Outcome

Recovered $300K+ and cut production failures by 72%, contributing to the company's highest-grossing year and first $1M revenue week.

PROJ-03Re-invent Finance Reporting

Context

Several Finance reporting processes each took about 3 hours a day and used outdated technologies.

What I did

Rebuilt report ingestion with multi-stage calculation layers and SQL Server bulk loading automations to create a more efficient and scalable solution.

Outcome

Average run time dropped to about 5 minutes and has been adopted by several departments across the organization.

PROJ-04Optimizing Production SQL Server Performance

Context

Production SQL Server queries were spending too long waiting, which affected users across our platform.

What I did

Analyzed waits with Database Performance Analyzer (DPA) and added targeted indexes. Identified deadlocks and optimized query execution plans.

Outcome

Query wait times fell by more than 60% and improved overall system responsiveness across all workflows.
