Slackwater

A small CSS design system built on one idea: the calm moment when the tide turns. One stylesheet, no framework, light and dark themes included.

<link rel="stylesheet" href="slackwater.css">

Color

Six named tokens do the work. Everything else is derived with color-mix or the theme variables (--bg, --surface, --ink, --muted, --accent).
